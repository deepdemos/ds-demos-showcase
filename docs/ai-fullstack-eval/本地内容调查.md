## 4. 为什么暂时还不能交给参赛 AI

目前能拿到部分作品文件，但没有一份已经核对完整的“约 50 件真实作品 + 元数据 + 资源 + 运行说明”包。

还需要补齐：

1. 确认完整备份是否另外存放；若没有，再确定真实内容的补齐方式。
2. 逐件对应线上 slug、标题、描述、公开作者、标签和创建时间。原始素材缺失这些信息时标记待补，不把文件修改时间当作发布时间，也不把编造标签记为线上原数据。
3. 去重、核对入口和封面，确认资源都在作品目录内并能离线运行。
4. 记录基准操作与结果，按 P1 schema 制作 manifest 和资源包，再冻结哈希。

可以先用少量合格的本地作品验证打包流程；如果预演要缩小至约 10 件，应在发题前同步调整并冻结运行记录。当前不声称已经达到约 50 件，更不声称已经取得 1000+ 的完整快照。
