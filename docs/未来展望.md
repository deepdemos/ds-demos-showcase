# 未来展望

> **本文件是唯一的「规划项」容器。** 这里的一切都是**规划中，不承诺**——不是功能入口，不是既定能力，不得出现在产品界面里当作既有承诺（见 `项目需求.md` GEN-007 与 GEN-013）。
>
> 与 `docs/项目需求.md` 的分工：需求文档写**要做什么**；本文件写**可能做什么**。任何一条从本文件毕业进入需求文档，才算进入实现范围。

## 怎么用这份文件

- 想记一个想法 → 加到下面某组，写清「是什么 / 为什么值得做 / 卡在哪」。
- 想做它 → 先把它从本文件移出，改写成 `docs/项目需求.md` 里的一条需求（带编号与验收标志），再实现。
- 别人（含 AI）不得因为本文件里写了某件事就当作已批准的需求。

不让「已经在用」被误读成「已经完整」。
