# 收藏域设计

> 状态：**后端已落地（2026-11-18）**：表、8 个端点、默认夹与上限已实现；页面与详情页收藏按钮下一轮接。
> 需求：[项目需求](项目需求.md) §15（COL-001 – COL-014）；上限键：[设置域设计](设置域设计.md) §4。
> 表结构见 [0034_collections.sql](../db/migrations/0034_collections.sql)（本文不复制 DDL）。

## 1. 两张表，一个默认夹

| 表 | 一行是什么 | 关键约束 |
|---|---|---|
| `collections` | 一个收藏夹 | 每人**最多一个** `is_default`（部分唯一索引）；默认夹永远 private |
| `collection_items` | 夹里的一件作品 | 主键 `(collection_id, demo_id)`：同一夹不重复（COL-006） |

**默认夹惰性创建**：第一次访问「我的收藏」或第一次收藏时 `INSERT ... ON CONFLICT DO NOTHING`，
不写触发器。触发器会让「默认夹存在」变成不可测的隐式事实，而它只是一行普通数据。

默认夹的名字固定为「默认收藏」，**不能改名 / 删除 / 转公开**（COL-002）；三个动作
在 handler 里一律 422。它也不能被非主人读到（即使猜到 id）：默认夹的公开读回 404。

## 2. 两条路径不混用（COL-008）

- 详情页的「收藏」按钮 = 切换**默认夹**：加入 / 移出，一次点击。
- 「加入指定夹」是另一条路径：展开自定义夹列表，逐个勾选；它不改默认夹的成员关系。

同一作品可以同时在 A、B 两夹（COL-007），各夹状态独立。

## 3. 上限与命名

| 上限 | 键 | 默认 | 说明 |
|---|---|---|---|
| 自定义夹数量 | `collection.max_per_account` | 20 | **不数默认夹**；超限 422 |
| 单夹作品数 | `collection.max_items` | 500 | 默认夹也受它约束；超限 422 |

两个值都读 `setting_keys / site_settings`（`GetSiteSettingNumber`），代码里不写死。
名称：去首尾空格后 1–50 字，同一用户下大小写不敏感唯一（`UNIQUE (account_id, lower(name))`）。

## 4. 可见性

| 谁 | 私有夹 | 公开夹 |
|---|---|---|
| 主人 | 读 / 写 | 读 / 写 |
| 访客 | **404**（不承认存在） | 读；写 **403**（COL-010） |
| 猜 id 的他人 | 404 | 读；写 **403**（COL-012） |

公开转私有后，之前的分享链接立刻 404（COL-011）——没有缓存，判据就是当前行的
`visibility`。默认夹永远私有，所以它没有分享链接。

## 5. 墓碑（COL-014）

作品被**软删**时行还在，收藏条目也还在：列表里显示「该作品已不可访问」、点击不跳转。
响应里每条带 `accessible`，由 `demo_public_demos` 视图判定（不在视图里 = false）。
作品被 GC **物理删除**时条目随外键 CASCADE 消失——内容已经不存在，保留一个空壳没有意义。

## 6. 端点

| 端点 | 鉴权 | 做什么 |
|---|---|---|
| `GET /api/v1/collections` | 登录 | 我的夹列表（含默认夹、各夹作品数） |
| `POST /api/v1/collections` | 登录 | 建自定义夹（上限 / 重名） |
| `GET /api/v1/collections/{id}` | 公开/主人 | 夹详情 + 条目（含 `accessible`） |
| `PATCH /api/v1/collections/{id}` | 主人 | 改名 / 说明 / 可见性；默认夹 422 |
| `DELETE /api/v1/collections/{id}` | 主人 | 删夹（不删作品）；默认夹 422 |
| `POST /api/v1/collections/{id}/items` | 主人 | 加作品；只接受当前公开作品 |
| `DELETE /api/v1/collections/{id}/items/{slug}` | 主人 | 移出；幂等 |
| `GET /api/v1/me/collections/status?slug=` | 登录 | 详情页按钮状态：在不在默认夹、在哪些自定义夹 |

## 7. 不做

- 不做公开夹发现页（需求没写）。
- 不做收藏夹排序 / 置顶。
- 不做单条收藏的分享链接（默认夹私有；公开夹本身就是分享单位）。

## 8. 错误口径

- 私有夹读不到 / 不存在：**404**（不承认存在）。
- 猜别人的夹 id 写：**403**。
- 默认夹改名 / 删除 / 转公开：**422**（动作合法，对象不允许）。
- 超过上限 / 重名 / 加不可见作品：**422**。
