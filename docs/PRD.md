## 1. 一句话

**把用 AI 做出来的东西，放到一个别人点开就能跑的地方。**

作者投稿（网页 / 压缩包 / Godot / 图片 / 三维模型 / 外链），站方审核后挂到渠道上，访客浏览、筛选、收藏。

【待拍板】这句话是否准确 —— 特别是「点开就能跑」是不是核心卖点，还是「可发现」才是。

## 2. 用户与核心场景

| 角色 | 他们来干什么 | 对应需求域 |
|---|---|---|
| **作者** | 把自己的作品传上来，看审核状态，改说明，知道「用的是哪个模型/哪一版」 | DEMO / ENT / IDN / MODEL |
| **访客** | 看别人的作品、按分类和模型筛、收藏、看浏览记录 | DEMO / TAG / MODEL / COL / HIST |
| **管理员** | 审作品、管分类词表、管站点参数、裁决提案与申诉 | GOV / LIFE / SET / CUR |

**主路径（一条就够）**：作者投稿 → 审核 → 挂上渠道 → 访客在列表里看到 → 点进去能跑 → 收藏。

【待拍板】是否需要第二条主路径（例如「按模型找作品」是独立的发现路径，还是附属筛选）。

## 4. 优先级

按「主路径上离用户最近的一步」排，不按域大小排：

- **P0**：身份（能登录）→ Demo（能投稿、能看）→ 治理（能审）→ 生命周期（能删、墓碑）。
- **P1**：分类与模型（能筛、能说明来源）→ 实体（提案与归属）→ 设置（运营开关）。
- **P2**：收藏 → 浏览历史 → 通知。
- **P3**：策展 → 公告 → 搜索。
- **不做**：见 [`项目需求.md` 附录 B](项目需求.md) 的 13 条。

【待拍板】这份排序是否与实际开发顺序一致 —— 现在的提交历史显示收藏/通知/公告比设置更早落地，与这里的排序相反。

## 5. 怎么算成功

【待拍板】这一节咱不敢替主人写。给三种可选的度量方式，选一个或换一个：

1. **主路径可跑**：从投稿到访客点开，全程无人工介入（除审核）。
2. **作者愿意回来**：有作者提交第二个作品。
3. **内容能自我解释**：任意一个作品详情页，不点开外部链接也能看懂「这是什么、谁做的、用什么做的」。
