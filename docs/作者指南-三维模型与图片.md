# 作者指南：三维模型与图片

面向投稿者。目标：导出的文件丢上来，审核通过后别人打开就能转、能看。

## 一、三维模型：交一个 `.glb`

平台收的是 **glb**（二进制 glTF），不收 `.gltf` + 外部 `.bin` + 贴图那一套：
后者是多个文件，而三维类型是单文件形态。

### Blender 导出步骤

1. 选中要导出的对象，`File → Export → glTF 2.0 (.glb/.gltf)`；
2. 格式选 **glTF Binary (.glb)**；
3. `Include` 只勾**选中的对象**（`Selected Objects`），避免把相机、灯光、脚手架一起带出去；
4. `Transform` 保持 `+Y up`（默认），不要自己改轴向；
5. `Geometry` 里 `Apply Modifiers` 勾上——不勾的话修改器效果不会写进导出结果；
6. 导出前 `Object → Apply → All Transforms`，把缩放归到 1，否则查看页里模型会偏大偏小。

### 贴图与压缩

- 贴图**内嵌**在 glb 里（导出时 `Images: Automatic`）；
- 尺寸控制在 2048 以内，4K 贴图会让单文件迅速膨胀；
- **不要开 Draco / KTX2 / meshopt 压缩**：查看页只内置了播放器本体，没有解码器，
  压缩过的模型会停在加载中（`docs/已知松点.md` 第 60 条）。这条是当前的硬限制，
  解开之后会单独通知。

### 打开之后是什么样

- 平台给这类作品一个**内置查看页**：可以旋转、缩放，页面上有「查看原始文件」的入口；
- 想直接拿原始字节（比如自己用工具打开），在地址后面加 `?raw=1`；
- 模型朝向不对通常是导出时改了轴向，或者场景里父级带了旋转——先在 Blender 里
  把变换应用掉再导。

## 二、图片：交一张 png / jpg / webp

- 三种格式都收，直接显示原图，不做二次压缩；
- 建议长边 2000 像素左右：再大对读者没意义，只是让首屏更慢；
- 截图请裁掉不该出现的个人信息（用户名、路径、桌面）。

## 三、类型怎么选

| 你交的文件 | 类型 |
| --- | --- |
| `.glb` | 三维模型 |
| `.png` / `.jpg` / `.webp` | 图片 |

选错类型会被服务端挡回来，提示里会写清楚检测到了哪种格式、这个类型收什么。

## 四、投稿之后

- `/preview/{slug}/` 可以自己先看效果（三维作品打开的就是查看页）；
- 审核通过后需要点「发布」才进作品库；
- 替换模型会生成新版本，线上内容在你发布新版本之前保持原样。
